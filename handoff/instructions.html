Penpal Backend — Final Setup

Connects form submissions to a Google Sheet, email notifications, and weekly/monthly analytics reports. Takes about 10 minutes. Must be done signed in as nationalcgoc@gmail.com.

Everything else is already live and tested. The signup page (https://daf-cgoc-2025.github.io/penpal/), the Firestore database, and the security rules are deployed and verified end-to-end — a test submission is already sitting in the database waiting for this setup to pick it up. This document covers the one remaining step.

What's in this kit

FileWhat it does
Code.gsChecks for new form submissions every 15 minutes, adds each one as a row in the Sheet, and emails nationalcgoc@gmail.com
ga4-reports.gsEmails a weekly (Mondays) and monthly (1st) website analytics summary: visitors, pages, time on page, countries, devices, file downloads
appsscript.jsonProject manifest — permissions the scripts need. Must be pasted exactly.

Setup steps

  1. Create the spreadsheet Go to drive.google.com (signed in as nationalcgoc@gmail.com) → + New → Google Sheets. Name it Penpal Intakes (top-left title box).
  2. Open the script editor In that spreadsheet: menu Extensions → Apps Script. A new tab opens with an empty project containing one file, Code.gs.
  3. Paste the main script Delete everything in Code.gs and paste the full contents of the kit's Code.gs. Press ⌘S / Ctrl-S to save.
  4. Add the reports script In the left Files panel, click + → Script. Name it ga4-reports. Delete the placeholder line and paste the contents of the kit's ga4-reports.gs. Save.
  5. Replace the manifest Click the gear icon (Project Settings) in the left rail → tick “Show ‘appsscript.json’ manifest file in editor.” Go back to the editor (< > icon), open appsscript.json, replace its contents with the kit's version. Save.
  6. Enable the Analytics service In the left Services panel click + → scroll to Google Analytics Data API → Add (keep the default identifier AnalyticsData).
  7. Run setup once In the toolbar above the code, use the function dropdown (it may say syncIntakes) → choose setup → click Run. An authorization window appears: choose nationalcgoc@gmail.com.
    You will see “Google hasn’t verified this app.” This is normal for your own private scripts. Click Advanced (bottom-left) → “Go to Penpal Intakes (unsafe)” → review → Allow. The warning appears because the script is yours, not a published app.
    the run finishes without red errors. This single run created all three automatic schedules (submission check every 15 min, weekly report, monthly report) and performed the first sync immediately.
  8. Verify Within a minute: the Sheet's Intakes tab has a header row plus one row — a test submission named “EndToEnd Test” — and nationalcgoc@gmail.com received an email titled [Penpal] New mentee intake — EndToEnd Test.
    that row and email prove the entire pipeline works. Delete the test row, and delete the matching test document in Firebase (console.firebase.google.com → DAFCGOC → Firestore Database → penpalIntake → the document whose duty location says “delete me” → ⋮ → Delete document).
  9. Optional: preview the analytics email Function dropdown → weeklyReport → Run. A “[DAF CGOC] Weekly analytics report” email arrives. (Data will be sparse until the dual-tagged pages have been live a few days.)

If something goes wrong

SymptomFix
“AnalyticsData is not defined”Step 6 was skipped — add the Google Analytics Data API service, then rerun.
“Firestore query failed (403)”You're signed in with the wrong Google account. The script must run as nationalcgoc@gmail.com (the Firebase project owner).
Authorization window never appearsYour browser blocked the popup — allow popups for script.google.com and click Run again.
No email after a test submissionEmails follow the 15-minute schedule. To force a check: function dropdown → syncIntakes → Run.
Temporary setting to remove later: both scripts currently BCC arkady232@gmail.com so the webmaster can verify delivery during launch testing. After launch is confirmed, edit the two lines marked TEMPORARY (TEST_BCC in Code.gs, REPORT_BCC in ga4-reports.gs) to empty quotes ''.
